# Delivery Chain — pakiet

Osiem skilli, lokalny CLI i generator HTML. Python 3.10+, macOS/Linux,
bez zależności zewnętrznych. Instrukcja instalacji i demonstracja znajdują się
w głównym README repozytorium. Samodzielne użycie:

```bash
python3 scripts/delivery.py --help
python3 -m unittest discover -s tests -v
python3 -m unittest discover -s skills/safe-web-delivery/tests -v
```

Kontrakt dziennika: references/journal.md. Wykonania zapisywane są w projekcie
użytkownika, poza katalogiem pluginu. Dziennik jest rejestrem deklaracji i dowodów,
nie źródłem uprawnień do publikacji ani potwierdzeniem prawdziwości zgody.
